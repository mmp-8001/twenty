# Followup is a custom object, not the standard Opportunity

A Followup is shaped like a deal: it has an Admin, a kind, deadlines and an outcome. Even so, it's defined as a custom object, and Opportunity is hidden. An app can only add fields to standard objects. It can't replace Opportunity's fixed `stage` options. Using Opportunity would mean a second status field next to the hidden standard one, plus exposure to upstream changes to Opportunity. The Followup object has its own `status` with the values from the CRM3 spec (#42): `pending_first_call`, `in_progress`, `rebuy_pending` while open, and `successful`, `expired`, `failed`, `no_answer_first_call`, `purchase_before_call`, `released_72h`, `transferred` once closed.
