## Follow-ups

- **RTL**: new upstream front code uses physical CSS properties (`margin-left`, `padding-right`, `left:`, `text-align: left` ...), mostly in Getting Started, chat bubbles, page layout and spreadsheet import. Re-run the logical-properties pass on files such as `getting-started/components/*`, `chat/components/StyledChatMessageBubble.tsx`, `page-layout/components/PageLayoutTabList.tsx`, `spreadsheet-import/*`, `record-list/components/RecordList.tsx`.
- **Jalali** (not checked): new upstream date displays, such as chat message time, may not go through the member calendar formatter.
- **Upgrade command**: our workspace member Calendar command lives in `2-55/`, but upstream is now on 2.58. A workspace already past 2.55 that never ran it will skip it. If any deployment needs it, move it into the current version folder with a new timestamp.
- **Lint**: run `npx nx lint:diff-with-main` for twenty-front and twenty-server against `upstream/main` to catch the new brace / no-else-return / prefer-const rules in fork code.
- **Push**: `feat/development` needs `git push --force-with-lease origin feat/development`. Local `main` and `origin/main` can fast-forward to `upstream/main` (origin/main has its one `.temp` commit to rebase or drop).
